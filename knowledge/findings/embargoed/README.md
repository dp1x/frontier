# Embargoed findings (gitignored except this README)

Findings that could constitute undisclosed vulnerabilities are stored here with
`disclosure: embargoed` or status `escalate/security-sensitive`. This directory
is in `.gitignore`; only this README is tracked.

Workflow: move the finding file here, stop automated disclosure, notify the
human. The human decides: coordinated disclosure, upstream report, publication,
or return to public knowledge with redactions. Nothing leaves this directory
without an explicit human decision recorded on the artifact.
