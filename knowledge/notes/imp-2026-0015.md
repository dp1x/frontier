# imp-2026-0015 — ZcashFoundation/frost (Rust, RFC 9591)

## Why this candidate

The Zcash Foundation's `frost` Rust workspace is the most production-grade
RFC 9591 FROST implementation available as of 2026-08-31. It is the only
candidate in the cohort that:

- Has explicit RFC 9591 Appendix A KAT coverage in its own test suite
  (`frost-core/src/tests/ciphersuite_generic.rs`).
- Was independently audited (NCC Group, public report 2023-10-23,
  commit `5fa17ed` / tag `v0.6.0`).
- Has been actively maintained through 2026 (HEAD commit on 2026-08-21
  is `0966bd1529aa062ad3b621af99e277f976b1c0f0`, PGP-signed by `conradoplg`).
- Ships the full feature set required by RFC 9591 Appendix C
  (trusted-dealer keygen, DKG, refresh share) inside a single workspace.

## Internal implementation choices (audit-relevant)

- **Binding factor hash**: `C::H1` (SHA-512 for Ed25519, SHA-256 for secp256k1,
  per RFC 9591 §6.1).
- **Preimage structure**: `pk_group || H4(msg) || H5(commitments) ||
  additional_prefix || identifier_serialize` — RFC 9591 §4.2 compliant.
- **Challenge hash**: `C::H2`, preimage `R || pk_group || msg`.
- **Hash-to-scalar**: `C::H3` (nonce generation), `C::H4` (message),
  `C::H5` (commitments list). NO use of RFC 9380 `hash_to_field`.
- **Lagrange basis**: naive product expansion in `compute_lagrange_coefficient`
  (not barycentric). Numerator and denominator computed separately, then
  inverted.
- **Participant identifier**: scalar field element (NOT length-prefixed,
  NOT fixed-width bytes). Default `IdentifierList::Default` produces
  1..=max_signers (1-indexed per RFC 9591 §4.2).
- **Serialization header**: length-prefixed 1-byte version + ciphersuite ID
  (`frost-core/src/serialization.rs`).

## Existing test infrastructure

- `frost-core/src/tests/ciphersuite_generic.rs` — generic RFC 9591 Appendix A
  KAT checks (shared by all ciphersuites).
- `frost-{ed25519,secp256k1,...}/tests/integration_tests.rs` — ciphersuite
  smoke tests.
- `frost-ed25519/tests/interoperability_tests.rs` — roundtrip against
  `ed25519-dalek`.
- `frost-{ed25519,secp256k1,...}/tests/recreation_tests.rs` — signing-share
  → secret reconstruction.
- `frost-{ed25519,secp256k1,...}/tests/serde_tests.rs` — serialization
  round-trip + JSON snapshots.
- No external KAT JSON fixtures; vectors are inline in test code.

## Known bugs / advisories

- **CVE-2024-28102** affected the pre-`frost-core` refactor `frost-rs` crate.
  Fixed in the v2.0.0 refactor that absorbed `frost-rs` into `frost-core`.
- NCC Group audit 2023-10-23 covered v0.6.0 (commit `5fa17ed`); all
  issues identified were fixed in subsequent releases.
- No active CVEs known against the pinned commit as of 2026-08-31.
