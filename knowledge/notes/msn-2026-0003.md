## What was actually proven (3 theorems, scope-disclosed)

For the **MODULUS half of FIPS 203 §7.2 (Eq 7.1) for d=12**:

  T1 (canonicalRoundtrip, L332-349): ∀ F, (∀ i, F i < 3329) →
      ∀ i, dec (encByte F) i = F i. Values below q survive
      Decode ∘ Encode.

  T2 (roundtrip_iff_canonical, L420-432): ∀ B, (∀ y, B y < 256) →
      (∀ i, seg B i < 3329) ↔ (∀ y, encByte (dec B) y = B y).
      Eq (7.1) holds iff every unreduced segment value is below q.

  T3 (minimalCounterexample, L440-451): the byte array
      B0 = fun y => if y=0 then 1 else if y=1 then 13 else 0
      has segment value 1 + 13*256 = 3329 = q at i=0, which
      decodes to 0 and re-encodes to 0x00 0x00 (NOT 0x01 0x0D).

**LENGTH half NOT formalized**: the model uses total functions
B : Nat → Nat, so the constraint `len(ek) = 384k+32` is not
expressible. Real implementations enforce it structurally via
byte-array typing before Decode is reachable; the formalization
proves the mathematical content of the modulus check only.
