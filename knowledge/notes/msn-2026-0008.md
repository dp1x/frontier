# msn-2026-0008 — HPKE X-Wing KEM cross-library differential (verified)

## Mission summary

Investigated whether independent X-Wing + HPKE implementations produce
byte-exact identical outputs for the same (encapsulation-key, message)
pairs. CIRCL (Go) is the only library shipping a turnkey X-Wing + HPKE
integration; other libraries require the operator to implement the X-Wing
combiner on top of primitives (X25519 + ML-KEM-768 + SHA3-256).

## Discovery phase

Spawned 6 parallel research scouts covering crypto/PQC, compilers, formal
math, interop/data-format, databases/other, and security. The HPKE X-Wing
target was independently surfaced by both the crypto scout (Candidate #1)
and the interop scout (Candidate #1) — a correlated-consensus signal.

## Adversarial review

Independent critic identified two errors that were corrected mid-mission:

1. **obs-2026-0028 v1 mislabeled mutations** — `eseed[0..31]` is the
   ML-KEM encapsulation seed (32-byte message `m`), NOT an X25519
   scalar. Only `eseed[32..63]` is the X25519 ephemeral scalar. The
   expected clamping behavior is at M32_0 (X25519 scalar byte 0 bit 0)
   and M63_7 (X25519 scalar byte 31 bit 7). The harness output was
   correct; only the labeling was wrong. **Corrected in obs-2026-0028 v2.**

2. **obs-2026-0029 v1 HPKE draft-07 vs RFC 9180 schedule divergence claim**
   was REFUTED: CIRCL's `circl/hpke/util.go` matches RFC 9180 §5.1
   byte-for-byte. The bug was in the Python reference (wrong suite_id="",
   wrong label `"nonce"` instead of `"base_nonce"`, wrong
   key_schedule_context shape). CIRCL passes 127 of 127 supported
   RFC 9180 test vectors. **Corrected in obs-2026-0029 v2.**

After corrections, the mission terminalizes as a verified_conclusion.

## Verified findings

- **CIRCL v1.6.5 X-Wing (draft-05) + HPKE (RFC 9180) is byte-exact conformant**
  per published KAT vectors.
- X-Wing draft-05 KAT hash matches `1bcd0057d861d6b866239936cadcaeee1ec0164dedc181c386e9e54fe46156fe`.
- RFC 9180 HPKE: 127 of 127 supported test vectors pass (export-only AEAD SKIPPED).
- Deterministic X-Wing Encapsulate + Decapsulate is byte-exact symmetric.
- HPKE Base mode Seal/Open is byte-exact symmetric.
- 28-mutation matrix exposes X25519 scalar clamping (RFC 7748 §5) at the
  documented positions (M32_0, M63_7); all other mutation positions
  change the ss (avalanche effect on ML-KEM seed).
- 100 random eseed samples produce 100 unique ss.

## What was NOT done

- **Cross-impl audit against Rust `hpke` crate, pyca/cryptography,
  libhpke, OpenSSL oqs-provider** — only CIRCL was exercised. This is
  the primary follow-up (msn-2026-0009).
- **Draft-08 KAT verification** — CIRCL implements draft-05 per its own
  docstring; the combiner order changed between draft-05 and draft-08.
- **SHA3-256 combiner input-order mutations** (M5 arg-swap, M6
  concat-order, M7 label-mixup) from the experiment design — deferred.

## Decisions and process

- Pinned CIRCL v1.6.5 (latest stable).
- Used `golang.org/x/crypto/hkdf` (the library CIRCL itself uses).
- Verified reproducibility via `verify_reproducibility.py` Python script
  comparing the harness output byte-exact against expected values from
  the previous run.
